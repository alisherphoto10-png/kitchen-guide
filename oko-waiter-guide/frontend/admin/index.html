Статусы блюд

Бейджи вроде «🔥 Хит» — свои, можно добавлять и переименовывать. Удаление статуса не удаляет блюда — у них просто снимается этот статус.

Импорт блюд из файла

.md-файл с блюдами по образцу формы (название, подзаголовок, описание, история, как подать, калькуляция) — заводит их все разом, вместо ручного ввода по одному. Фото и новые поля (статус, FAQ, аллергены) файлом не переносятся — добавляйте потом вручную по блюду.
