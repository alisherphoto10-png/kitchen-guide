# Логотип

Сюда кладём логотип KitchenDesk — иконка "KD" на зелёном фоне:
- SVG — основной, векторный вариант
- PNG — растровые копии (favicon, сайдбар, лендинг, футер экспортов)

Класть файлы также в исходники `oko-frontend/public/`, а не только в
задеплоенную папку — иначе теряются при пересборке.
