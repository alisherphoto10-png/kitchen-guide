OKO — управление заказами

Списки групп/тем заполняются автоматически по мере того, как бот видит там сообщения. Если нужной группы/темы ещё нет в списке — отправьте туда любое сообщение и обновите страницу, либо введите ID вручную.

Добавить заведение

Новое заведение появится ниже пустым карточкам — группу/тему для него подключаете точно так же, как для уже существующих. Не забудьте нажать «Сохранить все изменения» внизу.

Известные группы и темы

Названия тем Telegram отдаёт только в момент их создания — для уже существующих тем видно только номер. Впишите понятное название сами, оно запомнится и появится в выпадающих списках выше.
