Путь повара

Я лично прошёл весь путь повара в мини-приложении KitchenDesk — от входа через Telegram-бота до склада — и записал здесь, что видно на каждом экране и как это работает. Экран за экраном, вживую.

Вход в приложение

Точка входа — бот «KitchenDesk_Official». Команда /start открывает первый экран. Поток ниже — для сотрудника-повара, выбравшего «Я сотрудник».

Выберите, как вы хотите продолжить:

Экран 2 — код заведения

бот 🔑 Введите код приглашения (спросите у администратора ресторана):

В тексте бота — «код приглашения», по сути это код заведения: единый код, который администратор получает при регистрации и передаёт сотрудникам. Вводится текстом (в примере — «1»).

Экран 3 — ресторан найден, выбор имени

бот ✅ Ресторан найден: ОКО Гастробар
👤 Выберите ваше имя:

Список имён кнопками (Камиль, Назокят, Умида) — это сотрудники, которых администратор уже создал внутри самого KitchenDesk, не автоматически из iiko: «если в списке нету имени, значит администратор не добавил сотрудника».

Экран 4 — подтверждение, вход в кухню

бот ✅ Добро пожаловать, Камиль!
🏪 ОКО Гастробар
🔧 Цех: Пицца
Нажми кнопку чтобы открыть кухню:

Кнопка «🍽️ Открыть кухню» открывает само мини-приложение на вкладке «Главная». Доступ открывается уже в момент выбора имени на экране 3 — этот клик привязывает Telegram-аккаунт человека к записи сотрудника в KitchenDesk.

Обязательное условие

Прежде чем повар сможет пройти этот вход, администратор заранее должен:

  • создать сотрудника в KitchenDesk (с тем же именем);
  • присвоить ему роль «повар»;
  • назначить цех.

Если не сделано — сотрудника нет в списке на экране 3, войти нельзя. Это ожидаемое поведение, а не ошибка.

Вкладка нижнего меню · 2 из 7

ТТК

«Поиск ТТК» — список технико-технологических карт с фильтрами, и карточка рецепта с калькулятором пересчёта.

  • Фильтр по цехам — пилюли: «Все цеха» (по умолчанию), «Горячий цех», «Кондитерская», ещё (прокрутка вбок).
  • Поиск по названию — текстовое поле.
  • Фильтр по категории блюда — «Все», «гарнир», «десерты», «закуска», ещё.
  • Счётчик «Найдено: 329 рецептов», список карточек — фото, название, категория, стрелка вправо.

Карточка ТТК

Фото блюда во всю ширину — по нажатию открывается отдельно (просмотр/увеличение). Ниже: пилюля категории («закуска»), название, строка «Выход» (вес + штучно — «0.55 кг» / «1 шт»), заголовок «СОСТАВ» с кнопкой «🧮 Калькулятор», таблица ингредиентов (Ингредиент / Количество).

Внизу — «РЕЦЕПТ»: в примере пока заглушка «Описание приготовления скоро появится» — текст приготовления ещё не введён для этого ТТК, не баг.

Калькулятор пересчёта

Модальное окно, два режима на сегментированном тумблере: «Множитель» — число, на которое умножается каждый ингредиент; и «От количества» — выбирается один опорный ингредиент и вводится «сколько есть у меня», а система пересчитывает весь рецепт по тому же коэффициенту. Обе таблицы «РЕЗУЛЬТАТ» — колонки Ингредиент / Было / Стало (Стало — зелёным).

«От количества» пересчитывает пропорционально: коэффициент = (сколько есть) ÷ (сколько по рецепту) для выбранного ингредиента, этим же коэффициентом умножаются все остальные — по сути тот же «Множитель», только считается автоматически.

Смена

«Чек-лист смены» — чек-лист заготовок повара на сегодня. Список берётся из того, что запланировано в «Плане».

Заголовок «Чек-лист смены» + свой цех, переключатель дня «‹ Сегодня ›». Если на день ничего не планировали — экран прямо отправляет в «План».

Заполненный чек-лист

Карточка прогресса — «N / M задач выполнено» + круговой индикатор + прогресс-бар, обновляются сразу. Каждый пункт — пилюля с чекбоксом; отмеченные визуально опускаются вниз списка.

«+ Добавить позицию» — можно дописать пункт прямо здесь, вручную. Такой пункт попадает только в сегодняшний чек-лист — в «План» он задним числом не дописывается.

Завершение смены

приложение 🚩 Завершить смену?
Отчёт отправится в группу. Выполнено: 3/3

Необязательное поле «Заметка», кнопка «📤 Отправить отчёт». После отправки — «✅ Смена завершена! Отчёт отправлен в группу».

Отчёт действительно уходит в Telegram-группу заведения от бота KitchenDesk_Official (статус «Админ» в группе) — формат «ОТЧЁТ СМЕНЫ»: цех, повар, дата, «Выполнено: N из M», список выполненного, заметка. Отдельным авто-сообщением туда же уходит «📋 Новый план заготовок» — при сохранении плана (см. ниже).

План

«План заготовок» — здесь повар заполняет чек-лист на следующий день (или на сегодня/любой день вперёд); «Смена» на ту дату потом показывает этот же список.

Переключатель дня — не «сегодня/вчера», а вперёд: «Сегодня» / «Завтра» / конкретная дата. «Шаблоны для цеха не настроены» намекает на функцию администраторского шаблона (сам экран настройки не показан).

Выбор позиций

Список кандидатов здесь — часть, которая ещё дорабатывается: точный источник позиций в будущем изменится. Пока стабильно одно — выбранная позиция подсвечивается («загорается»).

При отметке появляется сводная строка «✓ Выбрано: N позиций» с кнопкой «Сбросить». Необязательная заметка к плану, кнопка «📤 Отправить план (N позиций)». После отправки — «✅ План отправлен!» + кнопка «+ Добавить ещё позиции» (дозаполнить план на ту же дату).

Отправленный план тоже уходит авто-сообщением «📋 Новый план заготовок» в Telegram-группу заведения.

Акты

«Акты разделки» — фиксация развеса при разделке (рыба/мясо), результат уходит администратору PDF-документом.

Выбор типа разделки

Список типов (иконка ножа, название, «N полей · отход авто») — в примере: Бон филе (6 полей), Говяжьи рёбра, Сибас (Гриль), Сибас (Хол. цех), Форель, Скерт (по 3 поля). Заранее настраивается администратором под позиции, которые в заведении разделывают.

Заполнение акта — пример «Форель»

Верхняя карточка — авто-подставленные Дата, Повар, Цех. Поля зависят от типа; для Форели — три:

ПолеПример
Общий вес (грязный)2 кг
Чистый вес0.6 кг
Отход (авто)1.400 кг — считается сам: общий − чистый

После отправки — «✅ Акт отправлен! PDF отправлен администратору». В отличие от смены/плана (уходят в Telegram-группу), акт разделки уходит именно администратору PDF-документом.

Вкладка нижнего меню · 6 из 7

Склад

Два режима — Закуп и Списание. Принцип у обоих одинаковый: повар только формирует черновик заявки, решение остаётся за администратором.

Закуп

Три кнопки: «Каталог», «Из ТТК», «+ Добавить» (вручную). Кнопку «Из ТТК» скоро уберём — автонаполнение закупа на основе ТТК больше не нужно.

Повар пишет в каталоге, что нужно и сколько, и отправляет — заявка уходит администратору на утверждение или корректировку. Каталог сгруппирован по алфавиту, каждая позиция — чекбокс, название, единица измерения (кг / шт / БП).

Списание

«Черновик списания» (сохраняется автоматически). Раздел «Чек-лист повара» — источник позиций: список для списания берётся из чек-листа повара. У выбранной позиции — бейдж «НОВАЯ» и подсказка «заполните», пока не указаны «Кол-во» и «Причина». Кнопка «📤 Готово (N)».

Заявка тоже уходит администратору, и если администратор подключил Telegram-группу — также и в группу. Интеграции с iiko по списанию нет — отдельный механизм внутри KitchenDesk.
