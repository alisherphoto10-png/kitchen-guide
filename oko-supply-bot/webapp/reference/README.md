пути (список товаров → проверка заказа по поставщикам → подтверждение отправки →
управление каталогом). Он ещё не передан в этот репозиторий — как появится,
положить файл прямо в эту папку.

Прототип не про код бэкенда, а про то, как должен ощущаться флоу — см. корневой
`CLAUDE.md` этого проекта, раздел «Прототип интерфейса».
