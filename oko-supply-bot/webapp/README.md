# WebApp

- `order.html` — рабочая форма: заказ (список товаров → проверка по
  поставщикам → отправка) и управление каталогом (⚙️ в шапке — товары,
  поставщики, включая `chat_id`). Загружает каталог и все изменения проводит
  через API, которое поднимает `../bot/webapp_server.py` — сама по себе,
  открытая напрямую файлом, работать не будет.
- `reference/order-prototype.html` — исходный кликабельный прототип (образец
  UX, откуда переносились экраны) — см. `../bot/README.md`, раздел
  «Форма заказа (webapp)».
