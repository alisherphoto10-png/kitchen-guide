# WebApp

- `order.html` — рабочая форма заказа (список товаров → проверка по
  поставщикам → отправка). Загружает каталог и отправляет заказ через
  API, которое поднимает `../bot/webapp_server.py` — сама по себе, открытая
  напрямую файлом, работать не будет.
- `reference/order-prototype.html` — исходный кликабельный прототип (образец
  UX), включая экраны управления каталогом, которых в рабочей версии пока
  нет — см. `../bot/README.md`, раздел «Форма заказа (webapp)».
