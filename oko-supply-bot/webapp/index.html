Рассылка поставщикам

Только уже известным поставщикам (с кем есть переписка по заказам) — новым контактам эта форма не пишет
Сообщения уходят по одному с паузой в несколько секунд — не одновременно всем, чтобы Telegram не расценил это как подозрительную активность.
