# oko-supply-bot

Весь контекст проекта — в `CLAUDE.md` (Claude Code читает его автоматически при старте
в этой папке). Начни сессию Claude Code прямо в этой директории.

## Структура

- `CLAUDE.md` — постановка задачи, архитектура, модель данных, с чего начинать код
- `webapp/reference/order-prototype.html` — кликабельный прототип UX (открыть в браузере)
- `data/Поставщики_и_товары.xlsx` — исходный список поставщиков и товаров (2 листа)
- `bot/` — сюда ляжет код userbot'а (Telethon): автоответчик + отправка заказов
