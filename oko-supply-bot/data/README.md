# Каталог товаров и поставщиков

`catalog.json` — источник правды по товарам и поставщикам для MVP. Синхронизацию
с Google Sheets (`Поставщики_и_товары.xlsx`) добавить позже.

Перенесено из `Поставщики_и_товары.xlsx` (26 поставщиков, 69 товаров). У всех
`chat_id` пока `null` — заполнять по мере появления реальных чатов с
поставщиками (см. `CLAUDE.md`, «Текущий статус по данным»).

Что поправлено или предположено при переносе — стоит перепроверить:
- **Единицы измерения (`unit`)** в исходном файле не были заполнены — проставлены
  по смыслу (кг для мяса/рыбы/сыров, шт для штучных товаров, л для жидкостей).
  Это предположение, не данные из таблицы — проверить и поправить вручную.
- **6 поставщиков без названия** в таблице (стояло «—», только контакт) получили
  временные имена вида `Без названия (грибы эноки)` — переименовать в карточке
  поставщика, как появится реальное название.
- **«Молоко Nestle 3,2%»** в исходном списке товаров случайно разбилось на два
  товара («молоко Nestle 3» и «2%») из-за запятой внутри «3,2%» — объединено
  обратно в одну позицию.

Модель данных (товар, поставщик, заказ) — см. корневой `CLAUDE.md`, раздел
«Модель данных».
