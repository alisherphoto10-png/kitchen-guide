# Каталог товаров и поставщиков

`catalog.json` — источник правды по товарам и поставщикам для MVP. Синхронизацию
с Google Sheets (`Поставщики_и_товары.xlsx`) добавить позже.

Сейчас там тестовый каталог (2 тестовых поставщика без `chat_id`) — по плану
из корневого `CLAUDE.md`: сначала обкатать механику на тестовых чатах, вручную
прописав их `chat_id` в `catalog.json`, и только потом заменить на реальных
26 поставщиков.

Модель данных (товар, поставщик, заказ) — см. корневой `CLAUDE.md`, раздел
«Модель данных».
