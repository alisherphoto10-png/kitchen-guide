# Часть 5 — упростить добавление блюда (меньше кликов), скролл всё ещё не работает

Живая проверка пользователем в реальном браузере (скриншоты) — большая
часть предыдущих частей подтверждена работающей (пункт меню «Банкет»,
форма создания, категории без «полуфабрикат», отметка «Добавлено», ⚠ в
финальном меню банкета). Осталось два пункта.

## 5.1 — слишком много шагов на одно блюдо

Сейчас в экране «Добавить блюдо»: у каждой позиции — степпер количества
(−/+) **и отдельная** кнопка «Добавить». Чтобы добавить блюдо на N порций,
нужно сначала N раз (или через степпер) выставить число, потом отдельно
нажать «Добавить» — два разных действия.

**Упростить:** клик по кнопке «Добавить» сразу добавляет блюдо в банкет с
1 порцией **и превращает саму кнопку в степпер** (−/+, как уже есть
визуально) — количество меняется уже у добавленного блюда, отдельного шага
«сначала выставь число, потом подтверди» быть не должно. Один клик = блюдо
в банкете.

Изменение количества после этого (степпером) должно сразу обновлять
реальные данные банкета (не только локальный счётчик до нажатия
«Добавить», как сейчас).

## 5.2 — скролл в списке выбора блюд всё ещё не работает

В прошлой части был сделан фикс (убран вложенный `overflow-y-auto`), но
пользователь подтверждает вживую: скролл по-прежнему не работает. Прежде
чем чинить заново вслепую:

1. Проверить, реально ли предыдущий фикс попал в задеплоенный бандл (тот
   же способ, что уже использовался в Части 4.1 — прочитать сам
   отданный `_next`-чанк, не полагаться на то, что сборка прошла).
2. Если фикс реально задеплоен, но проблема осталась — значит причина не в
   том, что предполагали (вложенный скролл), и нужно разбираться заново:
   возможно, у самого списка нет ограничения по высоте вообще (`overflow`
   без `max-height`/`height` ничего не даёт), или скролл блокируется
   родительским контейнером выше по дереву.
3. Voспроизвести с достаточным числом блюд, чтобы скролл был объективно
   нужен (список категории «Все» — 219 блюд, точно длиннее экрана).

## Проверка

1. Клик «Добавить» у блюда → сразу считается добавленным (как сейчас
   «✓ Добавлено»), кнопка сама становится степпером −/+.
2. Изменение количества степпером после добавления — сохраняется в
   реальных данных банкета, не только визуально.
3. Список категории «Все» (219 блюд) — реально скроллится внутри экрана
   выбора блюд, доступны все позиции, не только первый экран.

## Отчёт

Для 5.2 — обязательно объяснить, в чём была настоящая причина на этот раз
(и подтвердить, что новый фикс реально задеплоен, тем же способом
проверки бандла, что и раньше) — раз прошлый фикс не сработал, доверие к
одному только «должно быть исправлено» здесь ниже, чем обычно.
