# Часть 3 — форма создания банкета, предупреждения по наведению, скролл, категории у выбора блюд

По итогам макета (согласован с пользователем, макет:
https://claude.ai/code/artifact/574fbbfb-8b08-4945-aa5b-3e70696190ad —
можно открыть и свериться визуально, это утверждённый референс, не
предположение). Реализовать четыре связанных изменения.

## 3.1 — Форма создания банкета перед списком блюд

Сейчас (судя по скриншоту пользователя) клик «+ Новый банкет» либо сразу
создаёт банкет, либо сразу открывает пустой список блюд — без отдельного
шага ввода данных банкета.

**Нужно:** по клику «+ Новый банкет» — на месте, где обычно показывается
контент банкета (правая часть, там где список блюд у существующего
банкета), показать **форму**:
- Название банкета (текст).
- Дата.
- Количество гостей (число).
- Кнопка «Создать банкет».

После сохранения формы — **на этом же месте** открывается уже существующий
экран добавления блюд (тот, что было в Части 1/2), с уже созданным (пустым)
банкетом. Не отдельная страница/модалка — тот же правый блок контента
меняет своё содержимое в зависимости от шага.

## 3.2 — Предупреждения: иконка по наведению вместо блока (см. Часть с макетом выше)

Убрать большой красный блок со списком всех проблем перед меню банкета.
Вместо него:
- У каждого блюда в «Меню банкета», если по нему есть предупреждения (из
  `warnings`, уже реализованных в Части 1) — маленькая иконка-треугольник
  рядом с названием блюда.
- По наведению (hover) на иконку — всплывающая подсказка с текстом именно
  тех предупреждений, что относятся к этому блюду (не ко всем сразу).
- Внизу списка блюд — одна тихая строка-подсказка вида «N блюд из M требуют
  внимания», чтобы сигнал не терялся полностью для тех, кто не наводит
  мышью (см. макет).

## 3.3 — В PDF: предупреждения переносятся в конец документа

Сейчас (если предупреждения выводятся в PDF вообще) — уточнить порядок по
факту в коде. Нужно: раздел «Продукты для закупа» — сразу после меню
банкета, а список предупреждений — **отдельным блоком в самом конце
документа**, после закупа, не перед ним.

## 3.4 — Выбор блюд для добавления: категории, как на странице ТТК, плюс скролл

При добавлении блюда в банкет (кнопка «+ Добавить блюдо») — сейчас,
судя по всему, только поиск, без фильтра по категориям, и **список не
скроллится** (если блюд много — часть не видна/недоступна).

**Нужно:**
- Добавить те же чипы категорий, что уже есть на странице ТТК (Все /
  гарнир / горячее / десерт / закуска / соус / суп) — тот же компонент
  фильтра, не изобретать заново.
- Сделать список выбора блюд **скроллящимся** внутри своей области (сам
  диалог/панель не должен растягиваться на весь экран или обрезать список
  снизу).

## Проверка

1. Клик «+ Новый банкет» → форма (название/дата/гости) → сохранение →
   переход к добавлению блюд, всё на одном месте интерфейса, без лишней
   навигации.
2. Блюдо с предупреждениями — иконка видна, hover показывает именно его
   предупреждения; блюдо без предупреждений — иконки нет.
3. Строка-сводка внизу списка соответствует реальному числу блюд с
   проблемами.
4. PDF: закуп идёт до раздела предупреждений, не после.
5. Диалог добавления блюда — категории фильтруют список так же, как на
   странице ТТК; список скроллится, если блюд больше, чем помещается на
   экран.
