# Часть 9 — «Добавлено» не сбрасывается между разными банкетами

## Симптом (от пользователя)

1. Создал банкет 1, добавил блюдо (например «Баклажан с Тахини») — кнопка
   стала «✓ Добавлено», реально добавилось.
2. Создал банкет 2 (второй, отдельный), открыл «Добавить блюдо», то же
   самое блюдо в списке **сразу показывает «✓ Добавлено»**, хотя в банкет
   2 его ещё не добавляли.
3. По факту — блюда в банкете 2 нет (реального добавления не произошло),
   просто кнопка врёт.

## Вероятная причина (проверить, не считать готовым выводом)

Состояние «добавлено» у позиции в модалке выбора блюд, похоже, не
сбрасывается/не пересчитывается при смене выбранного банкета — либо:
- Хранится в локальном state компонента, который не размонтируется между
  открытиями модалки для разных банкетов (тот самый оптимистичный
  локальный флаг из Части 4.4 — «мгновенная локальная отметка сразу после
  успешного добавления» — вероятно, не привязан к `banquet_id`, просто
  держится в памяти компонента).
- Или сверяется с реальными позициями банкета (`banquetDetail.items`), но
  подтягивается не того банкета (закешированный старый ответ, не
  актуальный на смену `banquet_id`).

## Что нужно сделать

1. Воспроизвести ровно по шагам симптома выше — подтвердить.
2. Найти, где хранится флаг «добавлено» у позиции в модалке — привязан ли
   он к `banquet_id`, или общий на все банкеты.
3. Починить так, чтобы состояние «добавлено» **всегда** сверялось именно с
   текущим открытым банкетом — при смене банкета (или просто при каждом
   открытии модалки) состояние должно браться заново из реальных данных
   этого банкета, а не переноситься из предыдущего сеанса работы с
   модалкой.

## Проверка

1. Банкет 1 → добавить блюдо X → закрыть модалку.
2. Переключиться на банкет 2 (другой, реально отдельный) → открыть «Добавить
   блюдо» → блюдо X показывает обычную кнопку «Добавить», не «Добавлено».
3. Добавить блюдо X в банкет 2 → реально появляется в его меню банкета (не
   только кнопка меняется — проверить список позиций банкета 2 после
   закрытия модалки).
4. Вернуться на банкет 1 → блюдо X там по-прежнему показано как
   добавленное (проверка, что фикс не сломал обратную сторону — состояние
   не должно тоже неправильно сброситься там, где оно верное).

## Отчёт

В чём была причина (не привязано к banquet_id / кэш / что-то ещё), что
исправлено, результат проверки 1-4 — по возможности реальным кликом или
хотя бы прямым API-запросом на оба банкета, а не только по коду.
