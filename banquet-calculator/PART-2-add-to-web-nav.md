# Часть 2 — добавить «Банкет» в боковое меню веб-версии

Изменение решения по сравнению с Частью 1 (там специально исключили из
навигации, по аналогии с `oko-order`) — теперь просят добавить обратно, но
только в веб-версию (`/web/`), не в мобильную/мини-апп, если не уточнят
отдельно.

## Что сделать

В `Sidebar.tsx` (веб-версия) добавить пункт **«Банкет»**, ссылающийся на
`/banquet` — расположить **прямо перед пунктом «Профиль»** (последним
пунктом в текущем порядке меню, см. более ранние скриншоты структуры:
Главная / ТТК / Акты / Склад / … / Профиль).

Доступность пункта меню — тем же ролям, что уже пускает сам роут `/banquet`
(`admin`, `chef`, `sushef`, `cook` — см. `requireRole` в бэкенде,
подтверждено в отчёте Части 1), не показывать ролям, у которых и так нет
туда доступа.

## Проверка

1. Зайти под каждой из 4 ролей (`admin`, `chef`, `sushef`, `cook`) в
   `/web/` — пункт «Банкет» виден в меню, стоит прямо перед «Профиль»,
   переход по нему открывает `/banquet` и работает как раньше.
2. Если в системе есть роли без доступа к банкету (свериться со списком
   ролей из Части 1) — у них пункт не показывается вообще, не просто
   недоступен по клику.
3. Ничего не сломалось в остальной навигации (порядок остальных пунктов не
   съехал).

## Отчёт

Коротко: сделано, порядок пунктов меню после правки (список), результат
проверки по ролям.
