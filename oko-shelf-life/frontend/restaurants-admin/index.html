KitchenDesk — заведения

Заведения и принтеры

Каждое заведение — свой токен агента и свой список принтеров. Задание на печать уходит только тому заведению, которому принадлежит, и печатается на том принтере, который для него указан.

ID — только если это заведение уже известно ДРУГОМУ модулю под своим именем (например, приём заказов зовёт заведения "oblako"/"myaso" в своём конфиге) — впишите точно так же, иначе задания того модуля не найдут принтер. Для обычных заведений просто оставьте пустым.
