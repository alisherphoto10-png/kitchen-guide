# KitchenDesk — гид по экранам приложения

Собирается постепенно, по мере того как проходим экраны вживую (не по
памяти и не по коду вслепую — только то, что реально показано и
объяснено). Каждый раздел — один экран или один связный поток экранов:
что на нём, что каждая кнопка/поле делает, для кого он.

---

## Вход в приложение — поток для повара

Точка входа — Telegram-бот **@KitchenDeskOfficialBot** (отображается как
«KitchenDesk_Official»). Команда `/start` открывает первый экран.

### Экран 1 — приветствие, выбор способа входа

> 👋 Добро пожаловать в KitchenDesk!
> Выберите, как вы хотите продолжить:

Четыре кнопки:

| Кнопка | Назначение |
|---|---|
| 🧑‍🍳 **Я сотрудник** | Вход для сотрудника заведения (повар и т.п.) — по коду приглашения. Разобрано ниже. |
| 🔑 **Войти** | *(назначение пока не объяснено — уточнить отдельно, вероятно вход для админа/владельца по логину-паролю, не по коду.)* |
| 🎯 **Попробовать демо** | *(не объяснено — вероятно тестовый доступ без привязки к реальному заведению.)* |
| 🏠 **Зарегистрировать заведение** | *(не объяснено — вероятно онбординг нового ресторана/владельца.)* |

### Экран 2 — код приглашения

После «Я сотрудник» бот спрашивает:

> 🔑 Введите **код приглашения** (спросите у администратора ресторана):

Сотрудник вводит код текстом (в примере — `1`). Код — числовой, единый на
всё заведение (не персональный), выдаётся администратором ресторана.

### Экран 3 — ресторан найден, выбор имени

По коду бот сразу находит заведение:

> ✅ Ресторан найден: **ОКО Гастробар**
> 👤 Выберите ваше имя:

И показывает список имён кнопками (в примере — Камиль, Назокят, Умида).
**Это, судя по всему, список сотрудников этого ресторана, ещё не
привязанных ни к одному Telegram-аккаунту** — то есть тот самый механизм
сопоставления «сотрудник в системе ↔ конкретный человек в Telegram»,
который отдельно упоминался в связке с импортом графика/сотрудников из
iiko (сопоставление по имени). Не подтверждено окончательно, что это
именно тот список — уточнить.

### Экран 4 — подтверждение, вход в кухню

После выбора имени:

> ✅ Добро пожаловать, Камиль!
> 🏪 ОКО Гастробар
> 🔧 Цех: **Пицца**
> Нажми кнопку чтобы открыть кухню:

Кнопка **🍽️ Открыть кухню** — открывает само мини-приложение (Telegram
Mini App) на вкладке «Главная». «Цех» — рабочее подразделение, к
которому привязан этот сотрудник (используется дальше в приложении —
например, для чек-листа смены и коллег по цеху в графике).

### Открытые вопросы по этому потоку

- Что делают кнопки «Войти», «Попробовать демо», «Зарегистрировать
  заведение» — не показаны, не объяснены.
- Код приглашения (`1` для ОКО) — общий на всё заведение или можно
  выдать разные коды разным ролям/цехам? Не показано.
- Подтвердить точно, что список имён на экране 3 — это несопоставленные
  сотрудники именно из iiko-графика, а не отдельный, независимый список.
