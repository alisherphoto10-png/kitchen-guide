# Раскрытие «Склад» веером — инструкция по интеграции

Кнопка «Склад» в нижней навигации по тапу раскрывает дугой вверх две
подвкладки — Закуп и Списание — вместо прямого перехода в раздел. По
референсу из присланного видео-туториала (нажатие на центральную кнопку
раскрывает веер иконок), только форма кнопок — скруглённый квадрат, а не
круг (согласовано на прототипе, вариант A).

Прототип для сверки (обе формы, A выбрана): 
https://claude.ai/code/artifact/a22fb092-747e-43c3-aa7f-22e09767e728

Это временная папка-склад в репозитории `kitchen-guide` — код попал сюда
только для передачи на сервер, как остальные `oko-*` модули. После
интеграции можно удалить.

## Почему это черновик, а не готовый diff

Сам KitchenDesk не под git-версионированием — правки вносятся напрямую на
сервере через Claude Code, и файл нижней навигации (тот, что рендерит ряд
Главная/ТТК/Смена/План/Акты/Склад/Профиль) не находится в этом
репозитории — его не видно, чтобы написать точный патч по реальным
строкам. Технологический стек виден по соседним файлам в
`oko-iiko-integration/frontend/` (`IikoCard.tsx`,
`TtkManager-ingredients-field-part4.tsx`) — React + TypeScript + Tailwind +
`lucide-react` + `@tanstack/react-query`, Telegram Mini App (`useTelegram()`,
`haptic.success()/error()`) — `SkladNavButton.tsx` написан в точности в
этих же конвенциях (Tailwind-классы, включая произвольные значения в
скобках `bg-[#040816]`, `rounded-[14px]`, как в остальном коде; те же
цвета — `#040816`, `green-500`).

## Как встроить

1. Скопировать `frontend/SkladNavButton.tsx` в папку компонентов
   реального фронтенда KitchenDesk.
2. Найти компонент, где рендерится ряд нижней навигации.
3. Там, где сейчас «Склад» — обычная кнопка/`Link` с прямым переходом,
   заменить на:
   ```tsx
   <SkladNavButton
     active={текущийРаздел === 'sklad'}
     onNavigate={(tab) => navigate(tab === 'zakup' ? '/sklad/zakup' : '/sklad/spisanie')}
   />
   ```
   (подставить свой способ определения активного раздела и навигации —
   `react-router` `navigate()`, стейт вкладки и т.п., что уже используется
   для остальных пунктов меню).
4. Расстояние разлёта кнопок (70px по горизонтали, 18px вверх) подобрано
   под квадратную кнопку ~46px — если реальная ширина кнопки в ряду
   заметно другая, поправить `translate-x-[70px]` / `-translate-y-[18px]`
   на глаз, сравнивая с прототипом по ссылке выше.
5. Если в проекте есть `useTelegram()` с `haptic` (как в `IikoCard.tsx`) —
   раскомментировать импорт и добавить `haptic.impact('light')` на
   открытие/закрытие и на выбор подвкладки, для единообразия с остальными
   кнопками приложения.
