# kitchen-guide

Канал доставки не-текстовых файлов для проекта **KitchenDesk** (и связанного с ним
`oko-kitchen`) — того, что нельзя передать текстовым запросом: логотип, шрифты,
брендовые материалы.

Сам проект KitchenDesk не находится под git-версионированием (правки вносятся
напрямую на сервере через Claude Code). Этот репозиторий используется только
для передачи файлов на сервер.

## Структура

```
assets/
  logo/        — логотип KitchenDesk (иконка "KD" на зелёном фоне): SVG + PNG, favicon
  fonts/       — брендовые шрифты (.woff2 / .ttf): Space Grotesk (заголовки), Inter (тело)
  brand/       — цветовая палитра и гайд по стилю
  smm/
    october-2026/ — обложки постов/каруселей контент-плана KitchenDesk на октябрь.
      Имена файлов: post-DD.10.jpg (одиночный пост) или post-DD.10-N.jpg
      (слайд N карусели на эту дату). Подписи и даты публикации — в тексте,
      присланном отдельно (не в репозитории).
```

Файлы отсюда попадают на сервер вручную либо через `git pull` в папке проекта.
