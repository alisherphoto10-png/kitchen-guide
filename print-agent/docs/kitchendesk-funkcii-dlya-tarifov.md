# KitchenDesk: полный список функций (для разбивки по тарифам)

Составлено 2026-09-22 по реальному коду на сервере: бэкенд `/root/kitchendesk/backend`,
фронтенд кабинета `oko-frontend` и статические модули OKO в `/home/kitchendesk/frontend/*`.
В список попало только то, что сейчас реально работает. Незаконченное и удалённое
вынесено в отдельный раздел в конце.

## Как читать

**Роли** (так они называются в системе):
- **Повар**: обычный сотрудник цеха.
- **Су-шеф / Шеф-повар / Главный администратор**: руководство кухни. Им доступно
  «Управление», и права у них почти одинаковые. Где отличаются, это указано в пункте.
- **Официант**: работает только с пособием официанта, в KitchenDesk не входит.
- **Владелец**: хозяин заведения; в модулях OKO это тот, у кого есть пароль админки.
- **Супер-админ**: владелец платформы KitchenDesk (управляет всеми заведениями).

**Вес фичи** (оценка на глаз, для удобства разбивки по тарифам):
- ★ — мелочь или удобство, отдельно не продаётся
- ★★ — полезная функция, но не главная
- ★★★ — важная рабочая функция, ради неё пользуются системой каждый день
- ★★★★ — ключевая или «премиальная»: сложная, редкая у конкурентов, хорошо продаётся

**Тип модуля** (это важно для тарифов):
- **[Ядро]**: основная система KitchenDesk. Поддерживает много заведений, вход через Telegram или логин.
  Такой модуль можно включать и выключать по тарифу для любого клиента.
- **[OKO-модуль]**: сделан под заведение ОКО. Данные хранятся в отдельных файлах,
  вход по общему паролю админки. Работает **только для одного заведения**. Чтобы продавать его
  другим клиентам, нужна доработка под много заведений. Исключение — печать: её
  очередь и принтеры уже умеют работать с несколькими заведениями.

## 1. Вход, регистрация, демо, онбординг [Ядро]

### 1.1 Вход в Mini App через Telegram — ★★★
- Сотрудник открывает кухню кнопкой «🍽 Открыть кухню» в Telegram-боте, пароль не нужен.
- Первый вход: «Я сотрудник» → привязка к своему профилю в заведении, либо «Войти» по логину и паролю.
- Быстрый вход по PIN-коду (команда `/pin`), выход `/logout`.
- **Кто:** все сотрудники.

### 1.2 Веб-версия для компьютера («Доступ с ПК») — ★★★
- Отдельный вход на сайте `/web-login` по логину и паролю. Там полноценный кабинет с боковым меню.
- Логин и пароль для ПК сотрудник видит в своём профиле.
- Разделы те же, что в Mini App: ТТК, смена, план, акты, склад, управление. Для актов разделки
  в вебе есть отдельный табличный вид с фильтрами (см. 5.3).
- **Кто:** в основном руководство (шеф, администратор); повара тоже могут.

### 1.3 Регистрация заведения — ★★
- Заведение регистрируется с лендинга (заявка → регистрация → проверка статуса) или прямо из бота
  («Зарегистрировать заведение»).
- После регистрации главный администратор получает логин и пароль.
- **Кто:** будущий владелец или администратор.

### 1.4 Демо-режим — ★★
- Кнопка «🎯 Попробовать демо» в боте: открывается демо-кухня с готовыми данными. Изменения
  не сохраняются, сверху баннер «ДЕМО РЕЖИМ».
- Демо-сессию можно закрыть. Супер-админ видит конверсию «демо → регистрация» (см. 14.5).
- **Кто:** потенциальные клиенты.

### 1.5 Мастер первичной настройки (онбординг) — ★★
- Пошаговый мастер после регистрации: цеха, сотрудники, ТТК, продукты, пункты чек-листа.
- Блюда можно добавить по одному или вставить списком («по одному названию на строку»).
- На главной висит напоминание «Настройка не завершена → Продолжить».
- **Кто:** главный администратор.

## 2. Главная (дашборд) [Ядро]

### 2.1 Главный экран — ★★
- Приветствие, роль, статус «Смена сегодня».
- **Статус цехов**: по каждому цеху видно, заполнен ли план и какой процент выполнен.
- Быстрые действия: поиск ТТК, чек-лист, управление.
- Счётчики: цехов, поваров.
- **Кто:** все; статус всех цехов нужен в первую очередь руководству.

### 2.2 Лента уведомлений внутри приложения — ★
- Колокольчик со списком уведомлений, всплывающие тосты со звуком, «прочитать всё».
- **Кто:** все.

## 3. ТТК — технологические карты [Ядро]

### 3.1 База ТТК (просмотр) — ★★★
- Поиск по названию, фильтр по цехам и категориям, бесконечная прокрутка.
- Карточка блюда: фото, состав, выход, описание приготовления, КБЖУ на выход и на 100 г.
- Повар видит упрощённый состав (название + количество). Руководство видит полную
  номенклатуру: брутто, нетто, % потерь, единицы.
- **Кто:** все (просмотр); руководство — полный состав.

### 3.2 Калькулятор пересчёта ТТК — ★★★
- Кнопка «Калькулятор» в карточке блюда: пересчитывает весь состав на нужный выход или количество порций.
- Показывает «было → стало» по каждому ингредиенту. Строки без числа («по вкусу») не пересчитываются.
- Расчёт временный: в базе ничего не меняется.
- **Кто:** повара, руководство.

### 3.3 Экспорт ТТК в PDF и Excel — ★★
- «Скачать PDF» / «Скачать Excel» (калькуляционная карта с брендингом).
- Файл параллельно приходит в личный чат с ботом, чтобы его было удобно переслать.
- **Кто:** только шеф, су-шеф, главный администратор (поварам кнопка не показывается).

### 3.4 Управление ТТК (создание и редактирование) — ★★★
- Создание и редактирование ТТК: название, цех, категория, состав (структурированный: брутто,
  нетто, потери, единица), выход по весу или поштучно, КБЖУ, описание.
- Фото блюда (загрузить или удалить), архивирование, удаление.
- Полуфабрикаты (ПФ) связываются с блюдами, в которые входят (нужно для банкета и пересчёта).
- При изменении ТТК поварам уходит уведомление «Технологическая карта обновлена».
- **Кто:** шеф, су-шеф, главный администратор.

### 3.5 Импорт ТТК из файла выгрузки iiko — ★★
- Загрузка файла-выгрузки ТТК из iiko → предпросмотр «Готово к импорту» → массовое создание карт.
- Можно разом назначить цех и категорию выбранным блюдам.
- **Кто:** шеф, су-шеф, главный администратор.

### 3.6 Прямая интеграция с iiko (по API) — ★★★★
- Подключение к серверу iiko заведения (логин и пароль хранятся зашифрованно, TLS),
  кнопка «Проверить подключение».
- Выбор категорий из дерева iiko: что импортировать (кухня), что нет (бар).
- Импорт ТТК из iiko с предпросмотром. Отдельно показывается, сколько карт создано, сколько обновлено
  и сколько требуют ручной проверки. Есть PDF-отчёт об импорте.
- **Ночной автоимпорт** по расписанию (по умолчанию в 03:00), о результате уведомляются
  администратор, шеф и су-шеф.
- Состав блюд из iiko **заблокирован для ручной правки** в KitchenDesk: источник правды — iiko.
- Для клиента есть инструкция по созданию урезанного API-пользователя iiko (минимальные права).
- **Кто:** подключает супер-админ; результатом пользуются шеф и администратор.

## 4. Смена и план заготовок [Ядро]

### 4.1 План заготовок — ★★★
- Повар на своём цехе заполняет план на сегодня или завтра из шаблона цеха (отмечает позиции
  и количество) и отправляет.
- После отправки уведомление уходит руководству или в группу кухни.
- Можно сбросить и заполнить заново.
- **Кто:** повара (заполняют), руководство (получает).

### 4.2 Чек-лист смены — ★★★
- План превращается в чек-лист на день: отмечаешь выполненное, правишь позицию, можно добавить пункт.
- «Завершить смену» → отчёт о смене уходит в группу, чек-лист закрывается до завтра.
- **Кто:** повара.

### 4.3 Печать чек-листа смены на бумаге + завершение по QR — ★★★★
- При первом сохранении плана чек-лист автоматически печатается на кухонном чековом принтере.
  На бумаге есть QR-код.
- Повар сканирует QR телефоном, без входа в приложение. Открывается форма с галочками: отмечает
  сделанное и завершает смену. Отчёт уходит так же, как из приложения.
- QR действует только на свою смену и одноразовый.
- **Кто:** повара; настраивает руководство. Нужны принтер и агент печати (см. 11).

### 4.4 Шаблоны чек-листа / плана по цехам — ★★
- Для каждого цеха свой список позиций, из которого повар собирает план.
- **Кто:** шеф, су-шеф, главный администратор.

### 4.5 Перенос даты плана — ★
- Перенос плана с одной даты на другую, повара цеха получают уведомление.
- **Кто:** шеф, су-шеф, главный администратор.

### 4.6 История планов — ★★
- Архив отправленных планов по цехам и датам: в «Управлении» для руководства, в профиле свой.
- **Кто:** руководство; повар видит свою историю.

### 4.7 Мониторинг — ★★
- «Статус планов на сегодня»: какой цех отправил план, какой нет, процент выполнения.
- **Кто:** руководство.

## 5. Акты разделки [Ядро]

### 5.1 Создание акта разделки — ★★★
- Повар выбирает тип разделки (шаблон: например «Сибас», «Говяжьи рёбра», «Форель»), вводит веса
  (приход/грязный вес, чистый вес, обрезки, стафф, штучно и т.п.).
- **Отход и % отхода считаются автоматически.**
- Заметка, дата, история своих актов, повторная отправка после доработки.
- Анимированное подтверждение «Акт ушёл на утверждение».
- **Кто:** повара.

### 5.2 Согласование актов — ★★★
- Руководство подтверждает акт, отклоняет его или возвращает на доработку (с комментарием).
- Уведомления: «новый акт ждёт подтверждения», «акт согласован» (с PDF), «отклонён / возвращён».
- PDF акта, экспорт акта.
- **Кто:** шеф, су-шеф, главный администратор.

### 5.3 Веб-реестр актов (для ПК) — ★★
- Таблица всех актов с фильтрами по цеху, повару, типу разделки, датам и статусу. В строках
  % отхода и действия с актом.
- **Кто:** руководство.

### 5.4 Шаблоны актов — ★★
- Руководство само создаёт типы разделки и набор полей для каждого.
- **Кто:** шеф, су-шеф, главный администратор.

## 6. Склад: закуп и списание [Ядро]

### 6.1 Закуп (бланк закупа) — ★★★
- Каталог продуктов с поиском: отмечаешь нужное, указываешь количество и дату закупа, «Отправить бланк».
- Подтверждённый список уходит в группу закупа или ответственному.
- **Кто:** повара и руководство.

### 6.2 Дополнительный закуп с согласованием — ★★
- Срочный доп. закуп после основного: создаётся заявка, руководство одобряет или отклоняет,
  все участники получают уведомления.
- **Кто:** повара создают, руководство согласует.

### 6.3 Списание — ★★★
- Акт списания: позиции из каталога, количество, причина.
- Черновик сохраняется автоматически. Можно «Отправить сейчас» или «Оставить сохранённым».
  Несохранённый черновик **сам отправится в 23:00** (время настраивается).
- История, повторная отправка, удаление.
- **Кто:** повара создают, руководство получает.

### 6.4 Справочники склада — ★
- Каталог продуктов для закупа и списания, единицы измерения, причины списания (их видят повара).
- **Кто:** шеф, су-шеф, главный администратор.

## 7. Банкеты (калькулятор банкета) — ★★★★ [Ядро]
- Руководство создаёт банкет и собирает меню из ТТК с тем же поиском и фильтрами, что в разделе ТТК.
- Система **сама раскладывает меню на продукты для закупа и полуфабрикаты**: проходит по всей цепочке
  ПФ и считает по брутто и нетто.
- Проблемные места (не разобрался состав, не найден ПФ) показываются предупреждениями,
  а не теряются молча.
- PDF банкета и кнопка «Отправить PDF администрации».
- **Кто:** шеф, су-шеф, главный администратор (вкладка «Банкет» видна только руководству).

## 8. Люди, цеха, график [Ядро]

### 8.1 Сотрудники — ★★★
- Добавление сотрудника (роль: главный администратор / шеф / су-шеф / повар / гость), назначение цеха.
- Смена имени, роли, пароля и PIN, удаление. При назначении руководящей роли новые данные для входа
  приходят обязательным уведомлением.
- **Кто:** шеф, су-шеф, главный администратор.

### 8.2 Цеха — ★★
- Создание, переименование и удаление цехов (горячий, холодный, гриль, кондитерский и т.д.).
  Цеха используются в планах, шаблонах и мониторинге.
- **Кто:** руководство.

### 8.3 График работы — ★★
- Ручной график выходов по дням (работает / не работает), массовое заполнение.
- Сотрудник видит «Мой график» в профиле.
- **Кто:** руководство заполняет, сотрудник смотрит.

### 8.4 График дежурств (уборка камер и питание персонала) — ★★
- Загрузка .xlsx с листами «Уборка камер» и «Питание», ручная правка.
- Напоминание «ты сегодня дежуришь» (13:00) и анонс дежурств на завтра (22:00).
- **Кто:** руководство загружает, повара получают напоминания.

### 8.5 Профиль сотрудника — ★
- Роль, цех (можно выбрать самому), статистика, аватар, мой график, история планов,
  данные для входа с ПК, поддержка.
- **Кто:** все.

## 9. Telegram: бот, группы, рассылки, уведомления [Ядро]

### 9.1 Подключение Telegram-групп — ★★★
- Бот добавляется в рабочие группы и темы: «Кухня», «Менеджеры», «Закуп», свои типы групп
  (`/setup`, `/connect`, `/addgroup`).
- Маршрутизация: что в какую группу или тему уходит.
- **Кто:** главный администратор, руководство.

### 9.2 Настройка уведомлений — ★★

  изменение ТТК, импорт из iiko, ежедневная сводка.

### 9.3 Автоматические напоминания и сводки — ★★★

- **Кто:** получают повара и руководство.

### 9.4 Рассылка сотрудникам — ★★
- Текстовое сообщение или сообщение с фото всем сотрудникам заведения.
- **Кто:** шеф, главный администратор.

### 9.5 Отправка файлов в чат — ★
- Любой экспорт (PDF, Excel, изображение) дублируется в чат с ботом.
- **Кто:** руководство.

## 11. Печать на кухонном принтере (агент печати) [частично мультизаведенческий]

### 11.1 Агент печати на компьютере заведения — ★★★★
- Небольшая программа на моноблоке (Windows): работает в фоне без окна, забирает задания
  из облака и печатает на сетевом чековом принтере (ESC/POS, кириллица, QR-коды).
- Запуск одним кликом (`start-agent.bat`), есть PDF-инструкция для установщика.
- **Обновляется сам** (при старте и раз в 6 часов). При старте печатает чек «агент жив».
- Локальная страница настроек принтера (IP, порт, кодировка, отступ, оформление шапки).
- Диагностика: отчёты о принтерах на сервер, поиск второго (USB, этикеточного) принтера.
- **Кто:** ставит установщик или администратор один раз, дальше работает само.

### 11.2 Панель печати `/print-admin/` — ★★
