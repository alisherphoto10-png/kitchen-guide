# Ова подтверждает отправку акта — инструкция по интеграции

Когда акт разделки успешно отправлен на утверждение, робот-талисман
Ова (тот же, что на маркетинговом сайте KitchenDesk) выскакивает с лёгким
пружинным подскоком и подтверждает это. Сам закрывается через 2.2 с, либо
по тапу мимо карточки.

Согласовано на прототипе:
https://claude.ai/code/artifact/6347b324-942f-4fc2-a36a-c0f9d9b44933

Это временная папка-склад в репозитории `kitchen-guide` — код попал сюда
только для передачи на сервер, как остальные модули. После интеграции
можно удалить.

## Структура

```
frontend/
  OvaActConfirm.tsx   — компонент целиком (JSX + CSS через <style> внутри,
                          без отдельного .css)
  ova-hero.png         — Ова, поза приветствия (сжатая копия оригинала
                          из web/src/assets/ova/ova-hero.png, ~200 КБ
                          вместо 1.1 МБ — для мобильного трафика)
```

## Как встроить

1. Скопировать оба файла из `frontend/` в папку компонентов реального
   мобильного фронтенда KitchenDesk (не в `web/` — там уже есть Ова для
   маркетингового сайта, это для мобильного приложения).
2. Найти место, где отправляется акт разделки (мутация на кнопке
   «Отправить акт» в разделе «Акты»), и подключить:
   ```tsx
   import { OvaActConfirm } from './OvaActConfirm'
   import ovaHero from './ova-hero.png'

   const [sent, setSent] = useState(false)

   const sendMutation = useMutation({
     mutationFn: submitAkt,
     onSuccess: () => setSent(true),
   })

   // ...в разметке экрана:
   <OvaActConfirm
     open={sent}
     onClose={() => setSent(false)}
     mascotSrc={ovaHero}
     subtitle={`№ ${akt.number} · ${akt.item} — обновится, как только администратор подтвердит`}
   />
   ```
3. Если в проекте есть `useTelegram()` с `haptic` (как в `IikoCard.tsx`) —
   раскомментировать импорт вверху файла и добавить `haptic.success()` в
   момент появления (см. комментарий в коде, первый `useEffect`).

## Почему анимация именно такая

(Подробнее — `.claude/skills/animate` в этом репозитории.)

- **Частота действия — редкая.** Акт разделки отправляют не сто раз в
  день — как раз тот случай, где уместна капля «души», а не только сухой
  фидбек.
- **Подскок — только на входе.** Выход быстрый, без пружины — как у
  тостов и модалок: заход эффектный, уход скромный.
- **Только `transform`/`opacity`** — ничего, что дёргает layout.
- **`prefers-reduced-motion` уважается** — вместо подскока мягкое
  проявление без движения.

## Проверено перед передачей

Файл нижней... то есть файл экрана «Акты» не в этом репозитории
(KitchenDesk не под git), поэтому точный diff не составить. Сам компонент
проверен по-настоящему:
- **Типы:** `tsc --noEmit` — чисто.
- **Рантайм:** собран esbuild'ом с реальными `react`/`react-dom` и
  реальным `ova-hero.png`, отрендерен в браузере. Проверено:
  появление с подскоком по клику, автозакрытие через заданное время (в
  тесте — 1.2 с) с полным размонтированием и сбросом состояния `open`,
  закрытие тапом по фону мимо карточки — всё отработало корректно с
  первого прогона.
